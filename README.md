# Product Management System

A **full-stack web application** designed for managing products with complete CRUD operations, inventory management, and secure user authentication. Built for small to medium businesses to efficiently manage their product catalog and stock.

## Features

- **User Authentication:** Secure login and registration system for admin and users.
- **Product CRUD Operations:** Create, read, update, and delete products.
- **Inventory Management:** Track stock levels and product availability.
- **Responsive Design:** Works on desktop, tablet, and mobile devices.
- **Optimized Backend:** Efficient data handling with Hibernate and MySQL.
- **Secure Data Handling:** Input validation and safe database operations.

## Tech Stack

- **Backend:** Java, JSP, Servlets, Hibernate
- **Database:** MySQL
- **Frontend:** Bootstrap
- **Version Control:** Git & GitHub
